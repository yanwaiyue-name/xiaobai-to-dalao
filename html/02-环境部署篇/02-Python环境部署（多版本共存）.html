02 环境部署篇 · 第 2 章：Python 环境部署（多版本共存）

← 上一章 ｜ 返回目录 ｜ 第 3 章：Node.js 环境部署 →

这章解决什么问题

  • 从零装好 Python，并且装完就能在命令行里用
  • 搞懂"为什么我装了却报'python' 不是内部或外部命令"
  • 学会用"虚拟环境"（venv）：给每个项目一个独立小房间，装包互不打架

前置要求

Windows 10 / 11，无其他要求。

第 1 步：下载安装

  1. 官网：https://www.python.org/downloads/ → 黄色大按钮下载最新稳定版（版本号随时间变，以官网显示为准，不必追求和教程截图一致）。
  2. 国内下载慢：华为镜像 https://mirrors.huaweicloud.com/python/ → 找对应版本 → amd64.exe 结尾的安装包。

⚠️ 安装界面上唯一的生死选项

双击安装包后的第一个界面，务必勾选：

☑ Add python.exe to PATH

然后再点 Install Now。

这是"装完不能用"最常见的原因——新手反馈的这类报错里，漏勾这一项占了大头（经验判断，没有官方统计）。漏了怎么办？别慌，看第 8 章（急救手册）补 PATH，或者卸载重装一遍（最快）。

✅ 验证安装

新开 PowerShell：

python --version
pip --version

分别输出版本号（如 Python 3.13.1）即成功。

⚠️ 如果输 python 弹出了微软商店：这是 Windows 的"应用执行别名"在捣乱。设置 → 应用 → 高级应用设置 → 应用执行别名 → 把 python.exe / python3.exe 两个开关关掉，再重开终端试试。

第 2 步（可选）：把 pip 换成国内源

先试官方源：现在 PyPI 在国内多数网络下能直连，先 pip install requests 跑一次，几秒能装完就不用改。

只有下载慢 / 超时时再换镜像：

pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

这条命令改的是当前用户的全局 pip 配置（写在 %APPDATA%\pip\pip.ini），以后所有项目都走这个源。镜像站同步有延迟，刚发布的包可能要等几小时到一天才出现。

不想改了 / 出问题要还原：

pip config unset global.index-url

更推荐的做法：给公司项目或要复现的实验，别动全局源，用临时参数——

pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple

注意：镜像源是第三方托管，下载的包以 PyPI 官方为准。对安全性要求高的项目（比如要写进生产环境依赖），优先用官方源，或换源后核对 pip download 拿到的包哈希是否与 PyPI 页面上的一致。

第 3 步：跑第一个程序

# 建个工作目录（路径别带中文！）
mkdir C:\code\hello
cd C:\code\hello

新建 hello.py 内容一行：

print("Hello, 大佬之路开始！")

运行：

python hello.py

第 4 步：虚拟环境（venv）——每个项目独立一套

为什么需要：A 项目要 requests 2.x，B 项目要 3.x，装一起必打架。虚拟环境就是给每个项目一个独立的"包柜子"。

cd C:\code\hello
python -m venv venv          # 创建（首次约 10 秒）
.\venv\Scripts\activate      # 激活：命令行前面出现 (venv) 字样
pip install requests         # 此时装的包只属于这个项目
deactivate                   # 退出虚拟环境

⚠️ PowerShell 首次执行 activate 报"禁止运行脚本"？开一个管理员 PowerShell 执行一次：

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

然后重开终端再 activate。

💡 多版本共存怎么办

  • 官方安装包多装几个版本时，用启动器调用：py -3.12 hello.py、py -3.13 hello.py（py --list 查看装了哪些）。
  • 需要频繁切换版本搞 AI / 数据科学？直接上 Miniconda（下载页），conda create -n py312 python=3.12 一条命令一个环境。新手先不装，等真有需要再说。

常见坑

现象|解法
`'python'不是内部或外部命令`|漏勾AddtoPATH→第8章补PATH或重装
输python弹微软商店|关闭"应用执行别名"（上文）
`pipinstall`半天没动静/超时|没换国内源，回第2步
`error:MicrosoftVisualC++14.0isrequired`|某些库要编译，先试`pipinstall--only-binary:all:包名`；还不行就装个[VSBuildTools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
项目代码里venv传给了别人|venv文件夹不该进git，写进`.gitignore`

## ✅ 验证全部完成

python --version     # 版本号
pip --version        # 版本号，且路径在 Python 目录下
python hello.py      # 打印出欢迎语
python -m venv venv  # 能建虚拟环境
