01 科学上网篇 · 第 4 章：订阅链接怎么导入、怎么更新

这章解决什么问题

  • 拿到订阅链接不知道往哪填
  • 节点列表一直不更新，朋友能连你不能连
  • 手机、电脑怎么共用一条订阅

前置要求

  • 已安装客户端（第 3 章）
  • 已有一条订阅链接（长这样：https://xxx.example.com/api/v1/client/subscribe?token=xxxxxxxx）

⚠️ 先背一条铁律

订阅链接 = 你的钥匙。 链接里的 token 就是你的身份凭证，谁拿到谁就能用你的套餐。所以：

  • ❌ 不发群、不发朋友圈、不发小红书
  • ❌ 不截图到公开平台（token 会拍进去）
  • ✅ 只存在自己的密码管理器或私人备忘里

Clash Verge Rev 导入步骤

  1. 复制机场后台给你的 Clash 订阅链接（注意别复制成官网地址）。
  2. 打开客户端 → 左侧"订阅"。
  3. 顶部输入框粘贴 → 点"导入"。
  4. 出现一张卡片，点它确认选中（选中状态会高亮）。
  5. 右键卡片 → "更新"，立刻拉一次最新节点。

其他客户端入口速查

客户端入口
v2rayN主界面 → 订阅分组 → 添加订阅
FlClash配置 → 右下角 + → 添加 URL
ClashMetaForAndroid配置 → 右上角 + → URL 导入
v2rayNG主界面右上角 → 订阅分组设置 → 添加
Shadowrocket首页 → 右上角 + → 类型选 Subscribe

💡 iOS 的 Shadowrocket 常用"剪贴板导入"：先复制订阅链接，再点 + 号，它会自动识别。

## 订阅更新的正确姿势

  • 手动更新：随时右键订阅卡片 → 更新。
  • 自动更新：设置里把更新间隔设为 1440 分钟（一天），太频繁没必要。
  • 机场后台改了密码/重置了订阅：旧链接立即失效，要去后台复制新链接重新导入。

## 什么时候需要"订阅转换"

如果机场只给你 V2Ray 格式链接，而你想用 Clash 系客户端（或反过来），需要一个转换服务把格式翻译一下。机场后台通常会直接提供"Clash 订阅 / V2Ray 订阅"两条链接，优先用机场自带的；实在没有再搜"订阅转换 subconverter"，⚠️ 转换服务能看到你的订阅内容，只用知名、口碑好的，用完就换掉链接。

## 常见坑

现象原因
导入后节点是空的复制错了：复制成机场官网地址而不是订阅链接；或选错格式（Clash 链接喂给了 v2rayN）
链接导入报"无效"复制不全（末尾被截断）或带了空格，重新完整复制
别人能用你的订阅不能一条订阅通常限制 2～5 台设备同时在线，超出会互踢；也检查订阅是否过期
更新一直失败订阅域名本身被墙/换域名了，去机场后台看公告，换个域名再试

## ✅ 验证成功

  • 订阅卡片有节点列表（十几到上百个都正常）
  • 任选节点测延迟有数字
  • 浏览器能打开 github.com

三条全满足，这条订阅就算跑通了。
