这章解决什么问题

昨天还好好的，今天突然不行了。这章按"症状 → 原因 → 解法"组织，先给万能三步，再按症状细查。

💡 万能三步（先做这个，能解决绝大多数常见问题）

  1. 切换节点：代理页换一个节点（优先换个地区的），再测延迟。
  2. 更新订阅：右键订阅卡片 → 更新，让节点列表变新。
  3. 重启客户端：彻底退出（托盘图标右键退出）再打开。

三步做完还是不行，才往下按症状对号入座。

症状一：完全打不开任何外网

检查项怎么做
系统代理开关开了吗设置页 → "系统代理"是否点亮
订阅选中了吗订阅页 → 你的订阅卡片是否处于选中（高亮）状态
节点是不是全红代理页 → 测延迟，全 -1ms 说明节点全挂 → 换订阅/续费
是不是到期了登录机场后台看套餐有效期和剩余流量

## 症状二：能上 Google，但 B 站、淘宝打不开（或相反）

这是分流规则问题，不是断网：

  • 外网通、国内不通：规则页被改过或订阅自带的规则坏了 → 换用"全局"模式试试，能通就说明规则问题。
  • 国内通、外网不通：回到症状一排查。
  • 💡 平时用"规则模式"（自动分流），排错时切"全局模式"做对照，是最快的定位手段。

## 症状三：能连上，但是很慢

  • 换节点：同一机场换个地区（香港慢换日本、新加坡）。
  • 晚高峰（20:00～23:00）慢是线路超卖的特征 → 在第 5 章的"上车流程"里说过，晚高峰测速才是真标准。
  • 换协议：订阅里有 Hysteria2 节点就优先用，弱网/跨境链路上它比老协议快得多。
  • 测速基准：浏览器开 https://www.fast.com 看实时带宽。

## 症状四：老断流，隔几分钟掉一次

原因特征解法
网络切换WiFi 和手机热点来回切切换网络后手动重连节点
协议被针对每天固定时段掉换 Hysteria2/Trojan 节点
系统时间不准报"握手失败/timeout"（节点和你电脑"对暗号"没对上）见下方时间同步
DNS 污染（域名被"指错了路"）个别网站死活打不开，别人电脑却正常在客户端的 DNS 设置里改用 DoH/DoT 加密 DNS，并让域名交给节点远端解析。⚠️ 两个常见误解：Fake-IP 是一种 DNS 工作模式，不是"解污染开关"；把系统 DNS 换成 223.5.5.5 只能改善国内域名解析，对被污染的境外域名没用

时间同步（时间不准导致连不上是最常见原因，30 秒解决）：

# 以管理员身份打开 PowerShell，运行：
w32tm /resync

## 症状五：浏览器能用，Git / Docker / 命令行还是连不上

浏览器走系统代理，但命令行工具不自动走，要单独配代理。以 Git 为例（其他工具在第 2 篇各章里都有写法）：

git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897

⚠️ 端口号以你的客户端为准：Clash Verge Rev 默认 7897（设置页"端口"可以看到），老版 Clash 常是 7890。v2rayN 是 socks 10808、http 10809 两个端口同时存在，上面这种 http.proxy 必须填 HTTP 端口 10809，填 10808 会连不上——一切以客户端设置页显示的 HTTP 端口为准。

## 症状六：某个 App 死活不走代理

  • 浏览器插件类代理（SwitchyOmega 等）和系统代理打架 → 插件改回"系统代理"模式。
  • 有些软件不听"系统代理"指挥（命令行工具、个别 App）：可以研究 TUN 模式（设置 → 服务模式 + TUN，相当于"全屋总闸"），它有独立的学习成本，基本盘稳了再上。

## 还不行：看日志定位

客户端"日志"页，把等级调成 info，复现一次问题，找红色/黄色行。提 Issue 或问人时，把这几行日志 + 客户端版本 + 系统版本一起贴出来，比你描述"就是连不上"有用一百倍。

## ✅ 验证：排查有章法了吗

背一遍顺序：万能三步 → 认症状 → 对照表格 → 看日志。别一上来就重装软件，重装是最后的手段。
