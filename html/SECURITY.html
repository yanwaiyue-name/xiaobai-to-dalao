安全策略

报告问题

如果你发现本项目的安全问题（例如文档中包含可被滥用的敏感信息、脚本存在注入风险、CI 配置可能导致凭据泄露），请不要开公开 Issue。

请通过以下方式私下联系：

  • 在 GitHub 上给仓库所有者发私信，或
  • 开启一个标题为 [SECURITY] 的空白 Issue，只写"需要私下沟通"，不要写细节

我们会在收到后尽快回应。

本项目涉及的范围

这是一个面向零基础读者的计算机教程，包含大量可直接执行的命令，主要风险面包括：

  • 文档中的外链：可能被替换为钓鱼站
  • 自动化脚本：可能被恶意 PR 注入执行逻辑
  • CI 配置：可能被修改以泄露仓库凭据

不在范围内

  • 上游依赖自身的安全问题（请直接向上游报告）
  • 所列第三方服务的可用性或安全性
  • 社会工程学攻击
