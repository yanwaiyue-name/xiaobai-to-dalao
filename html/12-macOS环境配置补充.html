macOS 环境配置补充

← 返回目录

主教程以 Windows 为第一视角。这一页只列 macOS 上真正不一样的地方，避免照着 Windows 命令硬套。

1. 包管理器：用 Homebrew

macOS 没有官方的 winget 类工具，社区标准是 Homebrew。

# 安装 Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 验证
brew --version

常用命令对照：

操作|Windows（Scoop为例）|macOS（Homebrew）
安装|`scoopinstallgit`|`brewinstallgit`
更新|`scoopupdategit`|`brewupgradegit`
卸载|`scoopuninstallgit`|`brewuninstallgit`
搜索|`scoopsearchvim`|`brewsearchvim`

## 2. 环境变量：$env: 换成 $

PowerShell 与 zsh 的写法不同，这是最容易照搬出错的地方：

目的|WindowsPowerShell|macOSzsh
读变量|`$env:PATH`|`$PATH`
临时设变量|`$env:FOO="bar"`|`exportFOO=bar`
永久配置|系统属性→环境变量|写进`~/.zshrc`
生效|重开终端|`source~/.zshrc`

编辑配置：

nano ~/.zshrc
# 加入一行，例如：
export PATH="$HOME/.local/bin:$PATH"
# 保存后
source ~/.zshrc

## 3. Python：Homebrew 或 pyenv

# 直接装最新稳定版
brew install python

# 需要多版本共存时用 pyenv
brew install pyenv
echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.zshrc
echo 'export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(pyenv init -)"' >> ~/.zshrc
source ~/.zshrc

pyenv install 3.12
pyenv global 3.12

注意：macOS 自带的 /usr/bin/python3 是系统组件，不要删、不要覆盖。

## 4. Node.js：nvm 或 Homebrew

# nvm 方式
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# 重开终端后
nvm install 22
nvm use 22
nvm alias default 22

## 5. Git 与代理

# HTTPS 代理
git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897

# 取消代理
git config --global --unset http.proxy
git config --global --unset https.proxy

SSH 走代理需要在 ~/.ssh/config 里单独配置（端口按你的客户端实际设置改）。

## 6. 权限：sudo 与 chmod

  • macOS 对系统目录有保护，普通用户不能直接写入 /usr/local、/Library 等位置。
  • 安装到系统级位置时才用 sudo；Homebrew 安装的软件一般不需要 sudo。
  • 脚本没有执行权限时：
chmod +x ./script.sh
./script.sh

## 7. 自检清单

echo "Shell: $SHELL"

python3 --version
node --version

echo "$PATH" | tr ':' '\n'
