## 这个仓库解决什么问题

小白学电脑、学编程，最容易死在两件事上：

  1. 连不上网：想装个软件，官网打不开；想学技术，GitHub 卡成 PPT。而市面上的"科学上网"教程都默认你懂 VPN、机场、节点、订阅……没人从零讲。
  2. 环境配不好：Python 装了卸、卸了装，环境变量配了三遍还是报"不是内部或外部命令"。

所以这个仓库就两大篇 + 一个在建的进阶篇：

  • 01 科学上网篇：从"VPN 是什么"讲到"客户端能用、故障会修、坑都避开"
  • 02 环境部署篇：Git / Python / Node.js / Java / VS Code / Docker / MySQL，一个软件一章，照着做就能成
  • 99 进阶篇（建设中）：Linux、云服务器、建站、AI 工具

共 22 篇文档：17 章正文（01 篇 8 章 + 02 篇 9 章）+ 5 篇前言 / 附录 / 补充。
