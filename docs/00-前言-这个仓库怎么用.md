# 00 前言：这个仓库怎么用

[← 返回目录](../README.md)

## 这仓库写给谁

写给**完全零基础**的你：不知道 VPN 和机场有什么区别、装个 Python 能失败三次、听到"环境变量"就头疼。每一章都假设你从零开始，不跳步、不装懂。

## 两条阅读路线

**路线 A：我只想解决眼前的问题**

| 你的现状 | 直接看 |
|---|---|
| GitHub 打不开 / push 一直失败 | 科学上网篇 + 环境部署篇第 1 章 |
| 想学 Python 但连安装都过不去 | 环境部署篇第 2 章 |
| 软件装好了但报错 | 环境部署篇第 8 章（急救手册） |
| 被朋友安利了机场但不会用 | 科学上网篇第 1 → 4 章 |
| 想花钱买机场但怕被坑 | 科学上网篇第 5 章 |

**路线 B：我想系统学一遍**

按顺序从科学上网篇第 1 章读到环境部署篇最后一章，大概需要 2～3 个晚上。读完你就超过 80% 的同期小白了。

## 排版约定

- 所有命令都放在代码块里，**直接复制粘贴**即可，不用手敲：

```powershell
echo "像这样的一行，复制、粘贴、回车，三步搞定"
```

- 命令默认在 **Windows PowerShell**（或 CMD）里执行，两种都兼容。
- 涉及 macOS / 安卓 / iOS 的差异会单独标注。
- 全仓库的官网、下载页、社区问答出处都是**可点击链接**，点开就能跳到原网页看更详细的内容；集中速查见 [附录：官方网址速查表](10-官方网址速查表.md)。

## 遇到问题怎么办

1. 先翻**环境部署篇第 8 章（报错急救手册）**和**科学上网篇第 6 章（故障排查）**，80% 的报错都收录了。
2. 再看两篇的**社区精选问答**章（科学上网篇第 8 章、环境部署篇第 9 章）——整理自 GitHub / Stack Overflow / CSDN / 知乎的真实高频提问，附出处链接。
3. 还解决不了？去仓库提 Issue，请附上：
   - 系统版本（Win10 还是 Win11）
   - 报错**原文**（复制粘贴，别截图里抠字）
   - 你正在做的步骤和截图
