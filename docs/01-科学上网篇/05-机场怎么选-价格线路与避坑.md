## 这章解决什么问题

第一次买机场，面对几十家、眼花缭乱的套餐，怎么挑不踩坑。这一章给**判断标准**，不推荐具体商家。

💡 **具体机场名单别在本仓库找了**——机场变动快（今天活得好好的明天可能跑路），同账号的姊妹项目 [airport-nav](https://github.com/yanwaiyue-name/airport-nav) 每周自动体检机场入口的存活状态，去那边看"现在还活着"的列表。

## 先建立概念：机场的三六九等

| 档位 | 特征 | 适合 |
|---|---|---|
| 一线大机场 | 自建专线（IPLC/IEPL），价格贵，稳定 | 直播、视频会议、对稳定要求高 |
| 二线中坚 | 中转线路，性价比高 | **个人日常使用，推荐区间** |
| 小作坊 | 便宜甚至免费，质量看缘分 | 尝鲜、过渡 |

## 选机场看什么（按重要性排序）

### 1. 线路类型（决定速度下限）

- **IPLC / IEPL 专线**：内网专线，不过公网，稳且快，最贵。
- **中转（BGP/中继）**：国内服务器中转到境外，性价比之选。
- **直连**：从你家直连境外服务器，最容易堵，便宜但看运气。

💡 套餐页会写"线路：IEPL×3 + 中转×10"之类，**有专线节点的一般更靠谱**。

### 2. 协议支持

确认支持 **Clash 订阅** 和较新的协议（Trojan / Hysteria2）。只给老协议的小作坊慎重。

### 3. 套餐参数怎么读

以"20 元/月，200GB，3 台设备，10×节点"为例：

- **流量**：个人日常（网页+视频）每月 50～150GB 够用。
- **设备数限制**：电脑 + 手机同时在线至少要 2。
- ⚠️ 流量是否**每月重置**、有没有"空闲保号"机制，下单前问清客服。

### 4. 价格的心理价位

💰 个人日常用：**月付 10～30 元**是合理区间。低于 5 元/月还号称专线的，要么超卖严重要么准备跑路。

### 5. 稳定性与口碑

- 看 Telegram 群 / 社区口碑：搜名字 + "跑路""炸了"。
- 有没有**公开的公告频道**和及时客服。
- 运营年限：能活过 2 年的比刚开张的靠谱得多。

## ⚠️ 新手避坑十条（都血淋淋的）

1. **只买月付**。任何"年付 5 折"的诱惑，在你没验证它稳定前都是赌注。
2. **便宜到离谱必有坑**：超低价通常意味着超卖（几百人挤一条线）。
3. **拒绝个人收款码和 USDT 转账**：这两类都查不到对方身份，跑路后无从追讨。尽量走有订单号、有交易记录的平台下单。
4. **新站先观察**：刚开业送大额流量的，先收藏，观察 1～2 个月再上车。
5. **跑路前兆要认得**：客服失联、TG 群禁言、突然大幅打折清仓年付。
6. **"永久免费"是广告**：免费机场靠卖你的数据或引流回血，第 7 章细讲。
7. **不满速承诺别全信**：跑分软件测的带宽和实际体验是两回事，以自己试用为准。
8. **先买最短周期**：哪怕想长期用，也先月付测 1 个月速度和稳定性。
9. **查资质不如查历史**：这类服务本身无"正规资质"可言，看运营记录和口碑更实际。
10. **留好证据**：付款记录、订单截图，出维权情况用得上。

## 推荐的上车流程

```
看口碑 → 月付最小套餐 → 用 1~2 周（早中晚各测速）→ 稳定再考虑续费/升级
```

测速方法：客户端里选节点测延迟只是第一步，真正标准是**晚高峰（20:00-23:00）看 1080p 视频不转圈**。
