## 这章解决什么问题

你肯定听过这些词：VPN、梯子、机场、节点、订阅、SSR、Trojan……它们像黑话一样劝退了无数小白。这一章不教操作，只把**它们之间的关系**讲明白。搞懂了这章，后面装软件、买机场你才知道自己在干什么。

## 一个比喻讲清楚全部

把互联网想象成一个巨大的城市，你的电脑是**你家**，目标网站（比如 GitHub）是**商场**：

- 正常情况下，你出家门 → 沿大路 → 到商场，畅通无阻。
- 但有些商场（GitHub、Google）的路口被**门禁**拦住了，你的车过不去。
- **科学上网**就是：你先开车去一个**城外的中转站**（节点服务器），从中转站再到商场——门禁只查"大路口"，从中转站过来的车一路绿灯，商场也只看到你是从中转站来的。

所以整条链路是：

```
你的电脑 → 客户端（负责分流）→ 节点（中转服务器）→ 目标网站
```

记住这条链路，下面每个词都能对号入座。

## 名词逐个拆

### VPN（虚拟专用网络）

严格意义上 VPN 是一种企业组网技术，但在日常语境里，大家把所有"帮你绕路的软件"都叫 VPN。你只需要知道：**VPN = 你在客户端里连上某个节点，你的流量就从那里绕出去**。

### 节点

一台位于"墙外"的服务器，加上一组连接参数（地址、端口、协议、密码）。**节点 = 一个可以绕路的中转站**。一条订阅里通常有几十个节点，分布在香港、日本、新加坡、美国等地。离你越近、线路越好的节点，速度通常越快。

### 协议

你和节点之间"说话的方式"。常见的几种（知道名字就行，不用背）：

| 协议 | 一句话特点 |
|---|---|
| Shadowsocks（SS） | 老牌、轻量，现在较少单独用 |
| VMess / VLESS | V2Ray 家族协议，配置灵活 |
| Trojan | 伪装成正常 HTTPS 流量，抗干扰强 |
| Hysteria2 | 新一代，弱网环境下速度快、抗丢包 |
| TUIC | 也是新一代 UDP 协议，低延迟 |

💡 订阅里的节点用什么协议，客户端就得支持什么协议——主流客户端全都支持，你不用操心。

### 订阅（Subscription）

**一个网址**。客户端定期访问这个网址，就能拿到最新的节点列表。所以：

- 机场换了服务器、加了节点，你**什么都不用改**，客户端自动更新。
- ⚠️ 订阅链接里带你的私人凭证（token），**泄露 = 任何人都能白嫖你的套餐**，别发群里、别发朋友圈。

### 机场

卖订阅服务的商家。名字来源于早期订阅链接都以"机场"命名（XX 机场）。一个机场通常提供：

- 一条订阅链接（内含几十上百个节点）
- 后台面板（看流量用量、续费、重置订阅）
- 常见套餐：每月 10～30 元、100～300GB 流量，足够个人日常使用

💰 机场怎么挑、怎么避坑，是第 5 章的专题。

### 客户端

装在你电脑/手机上的**软件**，比如 Clash Verge、v2rayN。它负责三件事：

1. 导入订阅，拉取节点列表
2. 按规则分流：国内网站直连（不绕路），国外网站走节点
3. 连接/断开、测延迟、切换节点

### 流量分流（客户端最实用的功能）

好的客户端会自动判断：访问 B 站 → 直连；访问 GitHub → 走节点。你不需要每次手动开关，**挂着就行**。

## 关系图（一图流）

```
┌─────────┐    ┌──────────────────┐    ┌─────────┐    ┌──────────┐
│ 你的电脑 │ →  │ 客户端            │ →  │ 节点     │ →  │ 目标网站  │
│         │    │ （Clash Verge 等）│    │ （境外） │    │ (GitHub) │
└─────────┘    └────────┬─────────┘    └─────────┘    └──────────┘
                        │ 定时拉取
                 ┌──────┴──────┐
                 │ 订阅链接     │ ←── 机场提供（几十个节点打包）
                 └─────────────┘
```

## 常见疑问快答

**Q：免费节点能用吗？**
能连上，但风险多（速度慢、不稳定、流量可能被记录），第 7 章专门讲。学习尝鲜可以，别当主力。

**Q：我在学校/公司，装这个会被发现吗？**
本章不回答使用合规问题，请自行了解当地法规并阅读第 7 章。

**Q：为什么不用浏览器插件就行？**
插件只管浏览器这一个窗口，其他软件（Git、Docker、Python 下载依赖）全都管不到。客户端是全系统层面的，一劳永逸。

## ✅ 验证你学会了吗

不看上文，回答三个问题：

1. 订阅链接是什么？泄露了会怎样？
2. 客户端和节点，哪个装在你电脑上？
3. 访问国内网站时，流量会走节点吗？

（答案：一个带凭证的网址，泄露=被白嫖；客户端；不会，规则分流直连。）
