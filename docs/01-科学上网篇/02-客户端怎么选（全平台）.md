## 这章解决什么问题

第一次听说 Clash、v2rayN、Shadowrocket……根本不知道装哪个。这章一张表帮你选定，然后直接去下一章装。

## ⚠️ 先说最重要的原则

**只从官方 GitHub Releases 页面下载客户端。**

客户端是掌管你全部网络流量的软件，来路不明的安装包完全可能捆绑木马。认准下表里的官方仓库，其他任何"下载站""网盘版""绿色版"都不要碰。

## 怎么判断"订阅能不能用在这个客户端"

两种主流订阅格式：

- **Clash 订阅**：绝大多数机场都提供，上面 Clash 系客户端（Verge Rev / FlClash / Stash）直接吃。
- **V2Ray 通用链接**：`vmess://`、`vless://`、`trojan://`、`ss://` 开头的链接，v2rayN / v2rayNG 直接吃。

💡 现在主流机场后台会**同时给出两种格式**的订阅地址，你按所选客户端复制对应那条就行。买机场前在它的介绍页确认一下支持你选的客户端即可。

## 本仓库的路线

后面的教程以 **Windows + Clash Verge Rev** 为第一视角（用的人最多、教程最好写）。用其他客户端的读者：概念完全通用，只是按钮位置不同，配合各软件官方文档即可。
